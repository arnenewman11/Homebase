# Homebase

Source of truth for the Homebase task system: page code, data schema, manifest, scheduled-task instructions and data backups.
Live pages are hosted as claude.ai artifacts; this repo keeps their history.

- `pages/` – artifact page sources (Homebase, roadmaps)
- `data/store/` – canonical task store snapshot (areas, phases, tasks)
- `data/backups/` – dated exports
- `docs/` – blueprint and manifest
- `scheduled-tasks/` – instructions for each scheduled task
