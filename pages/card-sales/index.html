How this page stores its data

Everything lives in this page's own store, so Claude can read it, tick steps off, add log entries for you, or feed a dashboard from it.

  • tasks: id, track (comc | ebay | football), phase, title, detail, effort (S/M/L), kind (should/want), who (you/claude), due, status (todo/doing/done), order, doneAt, followup (cash | note), ask, note
  • phases: id, track, name, short, label, goal, milestone, reward, order
  • cash: date, channel, type (payout/sale), what, gross, net
  • time: date, channel, what, minutes
  • meta/state: leftOff, leftOffAt
